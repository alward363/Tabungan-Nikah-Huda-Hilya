Cara Pakai Permanen via GitHub

Agar aplikasi web ini bisa dibuka selamanya lewat link web sendiri, ikuti 3 langkah mudah berikut:

Langkah 1: Salin Kode Ini

Copy seluruh kode file HTML ini dengan tombol di bawah, lalu simpan di komputer/HP dengan nama file index.html.

Langkah 2: Buat Repository GitHub

Buka github.com, login, buat repository publik baru (misal: tabungan-nikah), lalu upload file index.html tersebut.

Langkah 3: Aktifkan GitHub Pages

Masuk ke menu Settings repository -> pilih Pages -> ubah Build and deployment Branch ke main / root -> Save. Selesai! Kamu akan mendapat link web permanen.
